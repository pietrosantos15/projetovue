# 🇧🇷 Brasil.lab — Landing Page Cultural

Uma landing page moderna, minimalista e responsiva dedicada a explorar e valorizar a pluralidade das manifestações, gastronomia, ritmos e patrimônio imaterial da cultura brasileira. Desenvolvida em **Vue 3 puro**, executando diretamente no navegador via **ES Modules / CDN**, sem necessidade de bundlers ou ferramentas de compilação.

---

## 🚀 Tecnologias

- **[Vue 3](https://vuejs.org/)** — Composition API com ES Modules nativos no navegador
- **HTML5 & Import Maps** — Mapeamento moderno de dependências sem etapa de build
- **CSS3 Puro** — Variáveis globais, Flexbox, CSS Grid e design system em modo escuro com estética brasileira

---

## 🎨 Funcionalidades

- **Identidade Visual Contemporânea**: Paleta moderna inspirada nas cores do Brasil (*Emerald Green*, *Vibrant Yellow* e *Sky Blue*) em harmonia com uma interface escura elegante.
- **Barra de Navegação Sticky**: Efeito glassmorphism translúcido e navegação suave (*smooth scroll*).
- **Métricas Culturais**: Indicadores estatísticos sobre tradições, povos e gêneros musicais nativos.
- **Grid de Pilares com Filtro Reativo**: Filtragem dinâmica por categorias (Música, Gastronomia, Folclore e Arte/Literatura).
- **Mosaico das 5 Regiões**: Apresentação dos polos e manifestações culturais regionais.
- **Newsletter Interativa**: Formulário reativo para recebimento de pílulas culturais semanais.
